# J-Quants レート制限（重要・常時参照）

## 公式情報（最終確認）
- 確認日: 2026-08-12
- 参照URL: https://jpx-jquants.com/ja/spec/rate-limits

## レート制限（V2）
- Lightプラン: 60リクエスト/分
- 参考: Free 5/分, Standard 120/分, Premium 500/分
- エンドポイント個別制限（プラン非依存）:
  - /v2/fins/summary: 60/分
  - /v2/fins/details: 60/分
- アドオン専用API制限（ベースプランと独立）:
  - 株価 分足・ティック: 60/分
  - TDnet/適時開示情報: 100/分
- 超過時: HTTP 429 Too Many Requests
- 大幅超過継続時: 約5分間の全面遮断の可能性

## このプロジェクトでの責務分離（重要）
- 本プロジェクトはライブラリとして他プロジェクトから利用される前提。
- リクエスト回数の上限制御・スロットリング・バックオフ・再試行ポリシー等の運用制御は、原則として**呼び出し側プロジェクトの責務**とする。
- 本ライブラリは必要に応じて429等を明示的に返し、呼び出し側が制御判断できる設計を優先する。
