# コラボレーション運用ルール（永続）

## 進め方
- 各フェーズで必ずユーザー確認を挟む。
- タスク分割は「意味のある最小単位」を優先する。
- 1ステップごとに目的・完了条件を短く示し、完了後に次ステップ着手前確認を行う。

## 実装スタイル
- ユーザーが自分でコードを書く前提（写経スタイル）で進める。
- ユーザーが明示的に「コードを生成して」と依頼するまで、AIはコード編集・生成・パッチ適用を行わない。
- それまでは、手順・差分方針・確認観点・レビューに徹する。

## 現在の技術コンテキスト
- 対象は `quantitative-data-analysis-rs`。
- 今フェーズは `aws_lambda_trend_analysis` を変更しない。
- 命名固定: `fetch_scoring_data` / `score_stocks` / `screen_stocks`。
- 出力先は `assets/` 配下。
- 後方互換は不要（破壊的変更可）。
- controllerレイヤー起点の3段実行を想定。
